# 🚀 Desi_AI

Desi_AI is a full-stack AI powered web application that allows users to generate articles, create blog titles, review resumes, generate images, remove image backgrounds, and more using modern AI models.

Built with React (Frontend) and Node.js + Express (Backend), Desi_AI integrates Groq LLM models for lightning-fast AI responses.

---

## ✨ Features

### 📝 AI Content Generation
- Generate full articles
- Create catchy blog titles
- Adjustable length control

### 📄 Resume Review (AI Powered)
- Upload PDF resume
- Get structured feedback
- Strengths & weaknesses analysis
- Professional improvement suggestions

### 🖼 AI Image Tools
- Text-to-image generation
- Remove background from images
- Remove objects from images

### 🔐 Authentication
- Secure authentication using Clerk
- Free vs Premium plan system
- Usage tracking

---

### Frontend
